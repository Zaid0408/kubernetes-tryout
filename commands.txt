# 1. Start Minikube
minikube start

# 2. Enable Ingress addon
minikube addons enable ingress

# 3. Use Minikube's Docker daemon (IMPORTANT!)
eval $(minikube docker-env)
# On Windows PowerShell use:
# minikube docker-env | Invoke-Expression

# 4. Build Docker images (from project root)
cd backend
docker build -t login-backend:latest .

cd ../frontend
docker build -t login-frontend:latest .

# 5. Verify images are in Minikube
docker images | grep login

# 6. Apply Kubernetes manifests (from project root)
cd ..
kubectl apply -f k8s/

# 7. Wait for pods to be ready
kubectl get pods -w
# Press Ctrl+C when all pods show "Running" and "2/2 READY"

# 8. Check services
kubectl get services

# 9. Check ingress
kubectl get ingress

# 10. Get Minikube IP
minikube ip
# Note this IP (e.g., 192.168.49.2)

# 11. Add to hosts file
# On Windows: C:\Windows\System32\drivers\etc\hosts
# On macOS/Linux: /etc/hosts
# Add this line (replace with your minikube IP):
# 192.168.49.2 login-app.local

# 12. Open in browser
# http://login-app.local

k9s
Open a terminal and run the k9s command. This will start the k9s tool and connect to your Kubernetes cluster.

In the k9s tool, you can use the arrow keys to navigate through the different views, such as the pods view, services view, and deployments view.

To view the pods, press the p key. This will display a list of pods in the cluster.

To view the ingress, press the i key. This will display a list of ingress resources in the cluster.

To view the details of a specific pod or ingress, select it in the list and press the Enter key. This will display detailed information about the selected resource.

To exit the k9s tool, press the q key.

To view Ingress resources in K9s, type :ingress or the shorter alias :ing into the command prompt. 
Here is how to do it:
Open K9s.
Press the colon : key to activate the command prompt at the bottom of the screen.
Type ingress or the alias ing.
Press Enter. 
Using k9s can be a helpful way to view and manage your Kubernetes resources in a more interactive way. It provides a console-like interface that allows you to navigate through different views and interact with your resources.
